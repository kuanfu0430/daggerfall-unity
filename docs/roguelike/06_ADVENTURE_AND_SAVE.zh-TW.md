# 06｜冒險閉環、角色成長、經濟與存讀檔

前置：[02 世界](02_BLOCK_WORLD.zh-TW.md)、[03 美術](03_ART_AND_EXPLORATION.zh-TW.md)、[04 戰鬥](04_TURN_COMBAT.zh-TW.md)、[05 裝備與效果](05_ITEMS_SPELLS_EFFECTS.zh-TW.md)。下一階段：[07 發行驗收](07_QA_AND_RELEASE.zh-TW.md)。

**本階段終點：**不是測試場，而是一個從標題畫面到勝利／死亡都能操作的遊戲。正常冒險不需開 console、生圖工具、Editor 或修改 JSON。

## Phase 06.1｜新遊戲、角色與固定 run

### 實作

標題畫面提供新遊戲、繼續／載入、操作說明、設定與離開。新遊戲提供近戰、弓箭、施法三種來源 preset，讓玩家看到屬性、技能、裝備和玩法差別。不必先做原 DFU 全角色背景問卷或所有 career 編輯器。

preset 從原 career／種族／item catalog 建立，具備對應武器、補給与起始法術；固定正常 reflexes，不要求玩家先理解原即時反應設定。被排除的跳躍／攀爬技能不佔可玩 preset 的主要成長欄位，不在配點 UI 出現。

建立 runId、worldSeed、資料 profile、rulesVersion、artCatalogVersion、初始世界時鐘、難度及獨立 RNG streams。第一次建立地牢 manifest 後，重新進入或讀檔不改圖、不重新擲任務位置。玩家可輸入 seed，空白則產生一次 seed 並保存；除這個建立 seed 的步驟，遊戲不得用實際時鐘影響結果。

MVP 採可手動存讀檔的單機冒險模式；死亡有結算，可重新開始或選擇先前存檔。嚴格永久死亡／反作弊不是本 goal 的需求，不為此引入強制限制。

### Gate

從新遊戲能以三種 preset 進入村莊；關閉後重開可繼續。源資料不足或參照不存在要在建立前明確失敗，不能到地牢才發現弓手沒有箭或法師沒有可用法術。

## Phase 06.2｜任務狀態與主路線

### 實作

正常遊戲有一個主要取回任務、一個短支線。可參考來源任務文本／類型並重用地點與 marker，但不在 MVP 強行載入整個原版主線狀態機。建立小型 objective adapter：

```text
NotAccepted → Active → ObjectiveObtained → TurnedIn → Completed
另有 Failed／Abandoned（僅適用允許放棄的支線）
```

主要流程：在村莊接受任務 → 地牢入口 → 門／開關／戰鬥与補給抉擇 → 指定 anchor 的任務物 → 原路或合法 Recall 返回 → 與 NPC 交付 → 結算。支線可以是清除來源敵人／收集指定物品，不另加新大型系統。

主要目標 anchor 從已凍結 manifest 選擇；保存 run、map instance、block instance、source marker 與物品 uid。不能讓畫面讀新布局、任務仍讀原 `MAPS.BSA` marker。原 `Place` 的 marker／site 身分關係是 adapter 的參考。[S13]

檢查任務所需道具的取得與返回路徑；不能把主線放在必須靠被排除的垂直技能才能到的地方。生成鑰匙／開關時驗證依賴。任務物可設不可賣／不可銷毀，但要在 UI 明說，且只針對必要任務物，不把一般道具全部加圍欄。

交付是原子交易：驗證正確任務和物品 → 消耗／標記任務物 → 給金錢或裝備／聲望 → 完成旗標 → 播放一次結算。讀檔或重開對話不能再領獎。殺怪支線由唯一死亡事件計數，不按屍體點擊次數。

### Gate

以玩家正常操作可接、完成主要任務並看到結算；支線可獨立完成／放棄。任務物跨圖與 Recall 不丟失。重複對話、領獎後存讀檔不会多給物品或金錢。

## Phase 06.3｜聚落服務與有意義的補給

### 實作

使用來源建築身分、名稱、派系、品質作服务绑定，商店、旅店／休息與任務 NPC 有不同入口与內容。商店以來源 item/value 与適用的交易公式定價；保留可影響它的 Mercantile／Personality／聲望等真正輸入，不能 UI 顯示折扣但扣原價。

提供買賣、補箭、補藥、修理、鑑定与至少基本法術取得；可由少量服务 NPC／選單共用，不必實作全套公會。交易以整數價格計算，來源需取整處照原規則；確認時再次驗證庫存、金錢、數量、負重與物品狀態，再原子提交。實際交易 baseCost 100，選單瀏覽不推進時間。

來源材料品質與最低命中材質要形成可理解的準備選擇。正常主路線在要求特定材料以前有可買、可找到或可回避的對應方法；不能用完全打不動且必殺的敵人堵住初始角色。

旅店按世界時間、費用与來源回復公式处理休息。地牢休息先確認附近危險与中斷条件，不能有敵人在旁仍一键滿血。休息會真實推進效果、毒、疾病、裝備損耗与日夜；強制限制只針對具體危險，不因「規範化」禁止所有非旅店休息。

聲望／反應、日夜／室內外附魔在這些服務中真的有作用。主要任務的必要交付途徑需保持可完成，不因測試附魔令唯一服務永久消失卻沒有替代路徑。

### Gate

玩家可補給後出發、帶戰利品回來賣、修復受損裝備、休息恢復並再次出發。交易／修理／鑑定成本與實際結果一致；不能以拆堆或存讀檔複製物品。

## Phase 06.4｜成長與難度收斂

### 實作

技能使用／訓練与升級沿用可抽離的來源計算，不因參考 NetHack 就改成「殺怪得通用 XP 升級」。有效使用對應技能、何時檢查進步、哪些 preset 技能參與等都在 rule-map 記錄。讀取原 `FormulaHelper`、技能／career 與 PlayerEntity 相關呼叫鏈完成適配，不只複製 UI 上的數字。

被停用的垂直技能不能仍參與必需的進度分母。先選擇不依賴它們的三個 preset，進步／訓練只顯示 active skills；未開放的全部 career 編輯器不在此 goal 中硬做。

玩家應能看見技能提升与装備提升；在快進測試中可驗證一次完整升級、血量／屬性變更与存檔。正常一輪是否升級由實測決定，不為保證快升級而無記錄地大幅改原始數值。

平衡優先調整低階來源敵人組合、出現數、地牢長度、補給、商店存貨与任務獎勵。若確實必須改時間／資源節奏，調整集中 profile 並留下來源與改編差異；不能在十個 handler 裡各補一個隱形倍率。

### Gate

三種 preset 都有可完成的主要路線；不是要求勝率 100%，而是不存在缺技能、缺必備材料、無法取得任務物等設計死鎖。失敗可理解、有準備／戰術選擇，而非無提示的 no-op 特效或資料錯誤。

## Phase 06.5｜完整存檔與跨場景時間

### 必須保存

```text
schemaVersion / sourceProfileHash / rulesVersion / runId
worldSeed + 已凍結的完整 manifests（不是只存 seed）
worldTick / scheduler 的必要狀態 / 全部 PRNG 狀態
玩家與敵人／召喚者的狀態、位置、生命／技能／裝備
物品 uid、庫存、耐久、毒、附魔、鑑定與歸屬
效果实例、剩餘時間、sourceItem/sourceEntity 与疊加關係
門、開關、容器、掉落、已探索格、任務與領獎狀態
商店狀態、派系／聲望、日夜、Recall 錨點
```

保存的是可重現狀態，不保存 GameObject／Transform 的記憶體地址。只在完整指令提交與事件結算後的安全邊界保存；動畫播放到一半時可以先完成結果，再保存，不把半支箭的物理狀態寫入。

同資料 profile／版本讀檔後，下一次骰與動作結果要和未關遊戲相同。不要在讀檔後重新附魔导致屬性加两次，或按新 generator 重新長出整張地圖。內容版本不相容時提供明確訊息及備份，不默默換成新世界。

同目錄暫存寫入、完整寫完後替換正式檔，保留一份可用備份与完整性摘要；讀到損壞檔時不要覆蓋好備份。提供至少三個手動 slot 和一個自動存檔位置。遊戲第一次存檔不要求管理員權限。

離開地圖後不模擬所有遠方敌人的尋路。地圖實體停在最後位置；需要時間語意的毒、效果到期、召喚期限与環境條件，依 global clock 在重載前確定性補算並處理死亡。這是明示的 MVP 離線地圖政策，不能利用換圖解除負面效果。

### Gate

同一輸入序列在以下節點存讀檔，最終世界 hash 与不讀檔相同：換裝後、附魔發動後、中毒中、使用 Recall 後、開門後、取得任務物後、交付後。召喚、效果與來源物品身份沒有 dangling refs；損壞 autosave 可保護既有手動 slot。

## Phase 06.6｜勝敗畫面与新手可操作性

### 實作

勝利顯示完成任務、用時／回合、主要戰利品与返回選項；死亡顯示原因、最近戰鬥 log、重新開始／載入選項。不能只有 exception、黑畫面或 console 字串。勝敗後不再讓敌人继续结算攻擊。

首次遊戲用短提示說明移動、碰撞近戰、方向射擊、施法、拾取、背包、門与上下樓。教學可跳過，操作說明可隨時開啟。核心流程可用鍵盤完成，不要求玩家猜熱鍵。

做一輪真正手動或 agent 操作 UI 的 playthrough，錄下截圖／輸入轨迹与版本；自動 simulation bot 只能補充，不證明 UI 操作一定可用。遊戲必須使用 03 的正式素材、04 的真實戰鬥与05的道具，而不是整合時換回假戰鬥。

### 交接

此時已是可以玩的候選版本，附一份正常存檔、可重現測試 seed、完整主要路線與操作記錄。直接進 07 做乾淨安裝、打包和回歸，不另開一輪需求分析。

來源边界：地點／任務據 [00 的 S9–S13](00_MASTER_PLAN.zh-TW.md#10-源碼與外部依據)；來源資料与公式據 S1–S4/S6。任務短篇範圍、slot 數、交易動作成本、離線地圖政策与預設存檔模式為本次設計。
