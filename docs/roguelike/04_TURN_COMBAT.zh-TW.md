# 04｜回合排程、碰撞近戰、方向遠程與敵人

前置：[01](01_FOUNDATION_AND_DATA.zh-TW.md)、[02](02_BLOCK_WORLD.zh-TW.md)、[03](03_ART_AND_EXPLORATION.zh-TW.md)。下一階段：[05 道具與效果](05_ITEMS_SPELLS_EFFECTS.zh-TW.md)。

**本階段終點：**正常畫面中能真正擊殺敵人、遭到攻擊及死亡；射箭和施法有方向、射程與遮擋。戰鬥操作取 NetHack 的方式，數值則用 DFU 的來源公式與物品／敵人資料，不混成第三套未說明的 d20 規則。

## Phase 04.1｜唯一排程器與時間帳本

### 已決定規則

使用整數 `nextActTick` 優先佇列，穩定 entity ID 作同 tick 排序。每次玩家有效動作先結算，再安排其下一個時間；依時間處理敵人及效果事件，直到玩家下次可行動。玩家選指令時世界停止，不在 Unity Update 自動打架。

基礎成本與速度映射如下。這些是 2D 節奏的明確新設定，不稱原作的動畫時間；源數值保留在 catalog。

```text
speedForScheduling = clamp(LiveSpeed, 25, 100)
Cost(baseCost) = ceil(baseCost * 50 / speedForScheduling)
100 ticks = 10 遊戲秒
600 ticks = 1 game-minute magic round
```

| 動作 | baseCost | 備註 |
|---|---:|---|
| 平地走一步／等待／近戰 | 100 | 八方向同成本，地形倍率另乘。 |
| 射箭 | 150 | 一次動作包含取箭和放箭，不要求持續按住拉弓。 |
| 施法／喝藥／使用道具 | 100 | 付費與效果在正式提交後才發生。 |
| 裝備或卸下一件／切換武器組 | 100 | 防止同一回合免費輪換附魔。 |
| 開關門／開容器／拾取一次選定項目／上下樓 | 100 | 開門不順便移動；UI 選清單本身不計時。 |
| 檢視、瞄準、取消、UI、存檔 | 0 | 不消耗任何 RNG。 |
| 明確無效：缺箭、缺魔、走進已知牆、不存在的物品 | 0 | 驗證失敗不改狀態。 |
| 有效但失敗：未命中、被抗性擋下、開鎖失敗 | 正常成本 | 不能利用失敗無限擲骰。 |

同 tick 的效果到期／週期傷害先按固定事件順序處理，再讓存活角色執行动作。死亡角色不得從 queue 復活行動。麻痺等不能輸入的狀態以強制等待推進，不讓遊戲卡在「等待玩家輸入」且效果永不消失。

敵人也是同一公式映射，不直接讀動畫 FPS 當移動速度。速度加成只在排程套一次，不再額外多給同回合攻擊次數；源多段攻擊另屬單次攻擊 payload。

### Gate

同速與倍速情境有確定行動數測試；快速角色不會使 DoT 按「自己多動一次」重複結算。開背包十秒與不開背包的遊戲狀態相同。0 成本指令不改時間和 RNG。來源分鐘持續效果依 global tick 而非畫面更新計算。

## Phase 04.2｜移動碰撞即近戰

### 實作

朝空格為移動；朝敌人所在的相鄰可交互格發出 `MeleeAttack`，角色留在原格。朝中立 NPC 開互動而不攻擊；强制攻擊中立目標需明確獨立操作。不要給每次玩家近戰額外自動反擊：敌人只有在自己的排程回合攻擊，否則會被打兩次。

把來源的命中／傷害流程分解為可測函式與事件：讀武器或徒手、技能与來源修正、最低材質檢查、命中部位、命中骰、傷害骰与修正、抗性／免疫、毒／附魔副作用、耐久、死亡及掉落。

保留 DFU `CalculateSuccessfulHit()` 的 3–97 clamp 及 `Dice100` 行為；保留武器 min/max 的端點、力量与材質修正、來源怪物特殊減傷。護甲的核心先維持其影響命中率与部位的來源意義，不自行改成另一套百分比減傷。Critical Strike 依來源公式，不自動補一個通用「20 就兩倍傷害」。[S4]

來源公式中與即時表現綁定部分作以下明確替換：揮擊方向為固定中性修正；弓箭不讀滑鼠按住時間；反應速度設定使用固定正常值；背刺以「敵人尚未察覺攻擊者」作 2D 條件並保留來源技能／倍率運算。這些改編需在 `rule-map` 與測試標示。

`AttackResult` 必須區分 Miss、HitNoDamage／MaterialIneffective、HitDamage、Killed，不能全部壓成 damage=0。UI 依真實原因回報，並且每次攻擊在 sourceDiceTrace 可追蹤但不洩漏正常玩法未知資訊。

來源可能在一次怪物攻擊中處理多段傷害。保留相應非零段與來源判定，不隨意把它們變成額外的敵人 scheduler 回合；感染、毒和觸發也按來源規定的命中時點執行。[S4]

### Gate

固定資料與固定骰序列精確對照來源；邊界機率、材質不足、空手、不同部位、多段敵人攻击、0 傷害與死亡各有測試。換裝會改變計算，而不是只有 UI 數字改變。原 `CalculateAttackDamage` 和新 event handler 不會雙重扣耐久或施毒。

## Phase 04.3｜方向投射物與射程

### 實作

`f` 選已裝備弓／箭，接八方向之一；滑鼠可選方向但不自動追蹤敵人。箭實際從 inventory 消耗，沒有弓或箭即 Reject。短弓射程預設 8 格、長弓 12 格；這是本版本格網映射設定，記在 `range-profile`，不假稱原值已是方格距離。

建立 `ProjectileSpec`：方向、maxRangeCells、travelMode、collisionPolicy、payload、element、回收政策。以確定性格位序列求路徑；每跨一個斜角，套用與移動一致的保守角落遮擋，不從兩堵牆的縫射出。

物理箭遇牆／關門停止；遇角色使用來源遠程命中計算。未命中可沿原方向繼續至下一格；真正撞中或材質無效即停止。一次放箭只扣一支，不是遇幾個角色扣幾支。回收先採固定規則：未撞中角色且終點可放物時落下一支，撞中角色的箭消耗；此為 MVP 設計值，避免增加不必要的隨機來源。

遠程攻擊不允許穿越不同 surface，跨層沒有自動彈道。投射動畫播放格位事件即可，不以 Rigidbody、collider 或 real-time travel time 判斷命中。跳過動畫結果相同。

`PreviewTrajectory` 與 `ResolveTrajectory` 共用同一格位演算法。預覽只顯示已知牆和視野內目標；實際行進仍會撞到未知遮擋，不能利用滑鼠探圖。

### Gate

八方向、最大射程、斜角、門、錯層、未命中後继续、零箭、取消與資源扣除均測試。畫面箭到哪、實際擊中哪、戰鬥 log 三者一致。

## Phase 04.4｜法術目標模式與基礎 payload

### 實作

使用 DFU `TargetTypes` 定義的五種模式：[S3]

| 來源目標模式 | 2D 交付行為 |
|---|---|
| CasterOnly | 直接施於自己。 |
| ByTouch | 選八方向相鄰格，必須同 surface 且可接觸。 |
| SingleTargetAtRange | 選方向、發出投射，依碰撞停在首個有效目標。 |
| AreaAroundCaster | 以自己為中心做阻牆範圍判定。 |
| AreaAtRange | 選方向，飛到碰撞／射程終點，在有效格產生範圍。 |

沒有可直接轉用的距離時，標準法術射程 8 格、範圍半徑 2 格；一律由明示 `range-profile` 配置。範圍使用同 surface 的受遮擋擴張，不越過實牆或關門；爆炸會影響範圍內敵我與施法者，免疫／豁免另算。

法術投射命中格位不等於使用武器技能擲一次物理命中骰。幾何接觸之後用來源效果的成功率、豁免、抗性、吸收与反射；不要額外加一個未定義的 d20 或射箭技能檢查。

本 phase 接入從來源選出的傷害、治療與一個工具法術，作完整端到端示範；05 再補滿共用效果與物品依賴閉包。這不是三個硬編碼特效後宣稱全部魔法完成。法術消耗在提交時扣一次；取消不扣，已施放但被抵抗仍扣。

### Gate

五種模式都有測試，至少傷害與治療可在正式 UI 使用；預覽與結果一致。AOE 不隔牆炸人，施法者被波及不漏判，抗性效果不是只改動畫顏色。

## Phase 04.5｜敵人 AI 與最小遭遇

### 實作

使用來源敵人能力與裝備，AI 採可測狀態機：idle／察覺／追蹤／攻擊／失去目標／死亡。近戰靠接近，遠程確認方向線与射程後射擊，施法者遵守魔力與成本。未具察覺的敵人不能讀玩家戰霧外座標；追擊使用最後已知位置。

A* 或 BFS 使用實際地圖連接、門、地形和 2D 能力，不用 renderer 的 sprite bounds。防止斜角穿牆、同格重疊与來回震盪。不能到達时等待或重新規劃，不能傳送到玩家旁。

至少配置八種來源敵人，normal run 中的首輪敵人選低階可擊敗的來源數值。必要的難度調整優先改变出现數量、距離、裝備與補給；若修改數值倍率，要標示 adaptation，不能無聲改掉來源資料。高階材質門檻敵人放在已有對應武器的区域或可回避支路。

死亡只觸發一次，移除行動能力、解除佔格並產生掉落事件。玩家死亡立即結束輸入与後續攻擊，轉給 06 的死亡流程。敵人自己的傷害、狀態与物品效果使用同一套 resolver，不維護兩份公式。

### 交接與 gate

有一個可操作的小遭遇：移動接敵、近戰、弓射、施法、治療、拾取、死亡皆可見且有聲音／訊息。保留來源對照測試与至少 100 組固定戰鬥種子回歸。更新 PROGRESS，接著 05，不以此小遭遇代替最終冒險。
